# Software Binaries Directory

Place the following application installer files inside this folder:

1. `OpenVPN.exe`
2. `MicroSIP.exe`
3. `Driver software for Windows-72.exe`
4. `PrintServer.exe`

> **Note regarding large files (>50MB):**
> If any of your executable files exceed 50 MB - 100 MB, enable **Git Large File Storage (Git LFS)** or host them on **GitHub Releases** to comply with GitHub's file size limits.
